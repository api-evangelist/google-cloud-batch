Breaking Logs from Batch jobs created after December 19, 2023 will no longer use the general-purpose generic_task monitored resource type and instead use the new batch.googleapis.com/Job monitored resource type. The batch.googleapis.com/Job monitored resource type is specific to Batch, which makes it simpler to query Cloud Logging for logs only from Batch.
